# Service incident response
## Regional degradation
An active sync-service incident can cause HTTP 503 with error code UPSTREAM_UNAVAILABLE. Check the customer's region and the incident's affected services. A regional incident is relevant only when those fields match. The incident feed is authoritative for current operational status.
## Escalation workflow
Prepare a concise escalation with account ID, product version, confirmed facts, affected service, incident ID when present, and unresolved questions. A support engineer must approve the exact draft before a ticket is created. Never state that a ticket was created without an execution receipt.
